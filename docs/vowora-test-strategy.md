# Vowora Test Strategy

## Dimensions

- Unit tests for utilities and components.
- Integration tests for API and data flows.
- E2E tests for critical user journeys.
- Accessibility and performance checks.

## Focus areas

- Role isolation.
- Plan limits.
- Object-level authorization.
- State transitions.
- Webhook idempotency.
- File ownership.
- Payment status and evidence labeling.

## Status

- **Partially implemented** — manual Playwright tests.
- **Planned** — automated test infrastructure.
