# Vowora API Versioning

## Versioning strategy

- Use URL versioning: `/api/v1`.
- Deprecate and support backward-compatible changes.
- Announce breaking changes in the changelog.

## Version lifecycle

- `v1` is current.
- Future versions are major updates.
- Remove old versions only after a complete migration period.

- **Planned** — backend versioning not yet implemented.
