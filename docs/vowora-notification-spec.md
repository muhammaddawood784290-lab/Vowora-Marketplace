# Vowora Notification Specification

Notifications are delivered through in-app records, email, and n8n workflows. Users control preferences by event type and channel.

Required events include assignments, requests, quote changes, proposal approval, invoice creation, payment status changes, subscription expiry, and security events. Delivery attempts, provider response, retry count, and final status are logged.

## Status

- **Partially implemented** — notification records and preferences exist.
- **Planned** — delivery pipeline and n8n workflows.
