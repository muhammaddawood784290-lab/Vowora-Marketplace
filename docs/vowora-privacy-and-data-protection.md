# Vowora Privacy and Data Protection

## Data categories

- Account information.
- Profile data.
- Event details.
- Communication records.
- Invoice and payment status.
- Uploaded files.

## Usage

- Account access.
- Matching and proposals.
- Notifications.
- Support.
- Security.
- Legal compliance.

## User rights

- Access.
- Correction.
- Export.
- Deletion where legally allowed.

## Controls

- Consent and retention policies configurable by country.
- Private files access-controlled and delivered using signed links.
- Never log passwords, tokens, or full payment evidence.

## Status

- **Partially implemented** — policy document and frontend demo auth.
- **Planned** — data protection controls and processing agreements.
