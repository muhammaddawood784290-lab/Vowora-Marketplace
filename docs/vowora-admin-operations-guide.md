# Vowora Admin Operations Guide

Admins manage verification, categories, plan entitlements, assignments, disputes, subscriptions, configuration, audit review, and support actions.

Sensitive changes require a reason, before/after values, actor, timestamp, and request ID. Historical financial facts are corrected by creating an auditable correction, not by silent edits.

## Status

- **Partially implemented** — admin pages and audit policy exist.
- **Planned** — full operations guide and tooling.
