# Vowora Recommendation Engine Spec

## Status

- Recommendation engine is a later module.

## Approach

- Start with explainable rules.
- Use event type, location, category, budget, availability, package fit, verification, response rate, and customer preferences.
- Later versions may add machine learning.
- Recommendations must not hide paid providers without disclosure or override customer approval.

## Status

- **Proposed** — recommend rules-based approach before machine learning.
