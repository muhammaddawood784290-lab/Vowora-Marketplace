# Vowora Frontend Design System

## Visual system

- Black text on white surfaces.
- Neutral gray borders and backgrounds.
- Monochrome icons.
- Clear spacing.
- Accessible contrast.

## Typography

- Sans-serif font stack.
- Base font size 1rem.
- Heading hierarchy: h1 through h6.

## Spacing

- Use CSS custom properties for spacing.
- Consistent gaps for layout, cards, and form items.

## Component rules

- Buttons: primary, secondary, ghost, danger.
- Cards: rounded corners, subtle borders, shadows.
- Tables: fixed header, row hover, status indicators.
- Forms: labels, hints, error messages.

- **Completed** — tokens, components, dashboard examples.
