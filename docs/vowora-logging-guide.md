# Vowora Logging Guide

## Structure

- Structured JSON logs for machine reading.
- Correlation IDs for tracebacks.
- Separate security logs from business logs.

## Log levels

- `error`
- `warn`
- `info`
- `debug`

## Forbidden content

- Passwords
- Tokens
- Full payment evidence
- Unnecessary personal data

## Status

- **Planned** — logging infrastructure not yet implemented.
