# Vowora Frontend Responsive Design

## Breakpoints

| Breakpoint | Usage |
| --- | --- |
| 375px | Mobile portrait. |
| 768px | Tablet portrait. |
| 1024px | Small laptop. |
| 1440px | Desktop. |

## Layout rules

- Landing page collapses to a single column on mobile.
- Customer dashboard uses a top header, tabs, and table-like data views.
- Vendor and planner dashboards use a shared shell with navigation.
- Admin shell uses a sidebar and content area.

## Testing

- Test at 375px, 768px, and 1440px.
- Verify horizontal overflow is absent.
- Verify touch targets are visible and interactive.
- Verify text remains readable and contrast is sufficient.

## Status

- **Implemented** — responsive markup.
- **Partially tested** — manual visual testing.
- **Planned** — automated responsive tests.
