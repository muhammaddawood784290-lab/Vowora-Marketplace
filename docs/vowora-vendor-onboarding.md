# Vowora Vendor Onboarding

## Flow

1. Vendor creates business profile.
2. Vendor adds services, packages, rates, availability, and portfolio.
3. Vendor submits verification documents.
4. Admin reviews verification.
5. Vendor is approved and can publish listings.

## Status

- **Partially implemented** — profile areas exist in the vendor and planner dashboards.
- **Planned** — verification workflow and admin review.
