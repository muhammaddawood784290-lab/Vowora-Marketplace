# Vowora Success Metrics

## North star metric

- **Completed events per month**, weighted by verified provider quality and customer satisfaction.

## Customer metrics

| Metric | Target | Notes |
| --- | --- | --- |
| Event briefs created | Growing | Free customers. |
| Event-to-proposal conversion | >60% | Briefs that lead to a proposal. |
| Shortlist-to-booking conversion | >40% | Shortlisted providers that lead to a booking. |
| Customer retention | >70% | Repeat event planners. |
| Support ticket volume | <2 per active event | Reduced by clear status tracking. |
| Delivery time | <24h | For status and invoice data queries. |

## Vendor metrics

| Metric | Target | Notes |
| --- | --- | --- |
| Requests received | Growing | Per vendor, per month. |
| Quote acceptance rate | >50% | Quotes accepted by customers. |
| Time to first quote | <24h | Average time from request to first quote. |
| Plan upgrade rate | >15% | Vendors upgrading from Silver to Gold. |
| Response time | <24h | Vendor response to requests. |
| Cancellation rate | <5% | Cancellations per booked event. |
| Completed events | Growing | Per vendor and per month. |

## Planner metrics

| Metric | Target | Notes |
| --- | --- | --- |
| Assigned events | Growing | Per planner, per month. |
| Completed events | Growing | Positive completion rate. |
| Proposal approval rate | >60% | Customer approvals of planner proposals. |
| Shortlist conversion | >50% | Shortlists that become booked bookings. |

## Platform metrics

| Metric | Target | Notes |
| --- | --- | --- |
| Uptime | 99.5% | Excluding planned maintenance. |
| p95 API read latency | <500ms | Dashboard and list queries. |
| p95 marketplace search latency | <1s | At agreed pilot scale. |
| Notification delivery | >98% | With retries and dead-letter handling. |
| Webhook delivery success | >99% | Idempotent and signed. |
| Audit record completeness | 100% | No gaps in sensitive operations. |
| Accessibility score | WCAG 2.2 AA | Core flows. |

## Financial metrics

- Organizer fee revenue.

- Backup restore success rate.
