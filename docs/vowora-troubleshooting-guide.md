# Vowora Troubleshooting Guide

## Common issues

- Login failing.
- Role access failure.
- Private file access errors.
- Invoice payment status mismatch.
- Plan limit encounters.
- Webhook delivery failures.
- Queue backlog.

## Steps

1. Reproduce locally.
2. Check logs.
3. Verify authentication state.
4. Verify database state.
5. Check queue workers.
6. Verify storage permissions.
