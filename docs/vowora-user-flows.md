# Vowora User Flows

## Customer

Browse marketplace → create account → create event brief → select or request planner → shortlist vendors → review proposal → approve or request changes → booking → track invoices and payment status → complete event.

## Vendor

Create profile → add services, packages, rates, portfolio, and availability → receive request → accept, reject, or counteroffer → submit quote → issue invoice → update status.

## Planner

Create profile → receive assignment → review event → manage shortlist → coordinate vendors → compare quotes → create proposal → customer approval → booking and event tracking.
