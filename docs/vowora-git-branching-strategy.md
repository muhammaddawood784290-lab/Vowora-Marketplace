# Vowora Git Branching Strategy

## Branches

- `main`: production-ready code.
- `release/*`: release preparation.
- `feature/*`: user-facing features.
- `hotfix/*`: production fixes.

## Process

1. Create a feature branch from `release`.
2. Open a pull request.
3. Review and approve.
4. Merge to `release`.
5. Create a release and deploy.

## Status

- **Proposed** — branching strategy is a recommendation, not yet implemented.
