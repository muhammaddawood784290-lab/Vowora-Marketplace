# Vowora Incident Response Plan

## Objective

Detect, contain, recover, and document incidents with minimal impact.

## Roles

- Incident commander.
- Engineering lead.
- Security lead.
- Product lead.
- DevOps lead.
- Communications lead.

## Severity levels

| Severity | Definition | Response time |
| --- | --- | --- |
| S1 | Major outage or data breach | 15 minutes |
| S2 | Significant degradation | 1 hour |
| S3 | Minor issue | Next business day |
| S4 | Cosmetic or low impact | Next sprint |

## Workflow

1. Detect and alert.
2. Triage and assign severity.
3. Contain the incident.
4. Mitigate impact.
5. Recover and restore service.
6. Verify affected users.
7. Document and review.

## Escalation

- Page on-call engineer.
- Escalate to security incident response if data is affected.
- Escalate to executive team for S1.
