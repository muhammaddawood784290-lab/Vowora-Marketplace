# Vowora Environment Configuration

## Environments

- Development.
- Staging.
- Production.

## Configuration

- Environment variables only.
- No secrets in code.
- Different configuration per environment.

## Required variables

- `VITE_API_BASE_URL`
- `VITE_API_CONNECTED`
- Database credentials.
- Object storage credentials.
- Queue credentials.
- Email provider credentials.
