# Vowora Data Loss Response

## Objectives

- Stop further data loss.
- Restore lost data where possible.
- Verify integrity.
- Document the event.

## Steps

1. Halt the suspected activity.
2. Preserve logs and backups.
3. Restore from backups.
4. Verify data integrity.
5. Notify stakeholders.
6. Document and prevent recurrence.

## Status

- **Planned** — procedures documented, drills recommended.
