# Vowora Production Incident Runbook

## Objective

Detect, contain, recover, and verify the service with minimal impact.

## Roles

- Incident commander.
- Engineering lead.
- Security lead.
- DevOps lead.
- Communications lead.

## Steps

1. Detect and alert.
2. Triage and assign severity.
3. Contain the incident.
4. Mitigate impact.
5. Recover.
6. Verify affected users.
7. Document and review.

## Escalation

- S1: page executives.
- S2: escalate after 1 hour.
- S3: handle on-stack with daily review.
