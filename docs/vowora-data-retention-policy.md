# Vowora Data Retention Policy

## Retention principles

- Collect only necessary data.
- Consent and retention configurable by country.
- Private files access-controlled with retention per object type.
- Delete user data where legally allowed.

## Object retention

| Object type | Retention |
| --- | --- |
| Identity documents | Per legal and verification requirements. |
| Event files | Per event lifecycle and legal hold. |
| Invoices | Per financial record requirements. |
| Audit events | Long-term retention for evidence. |

## Status

- **Planned** — retention configuration is not yet implemented.
