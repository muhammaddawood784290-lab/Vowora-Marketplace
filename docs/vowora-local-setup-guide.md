# Vowora Local Setup Guide

## Prerequisites

- Node 20 or later.
- Package manager of choice.
- PostgreSQL, Redis, and n8n for full development.

## Steps

1. Install dependencies.
2. Start the Vite dev server.
3. Use demo credentials for local login.
4. Configure `VITE_API_CONNECTED=true` to call the backend API.
