# Vowora Deployment Guide

## Prototype deployment vs production deployment

### Prototype deployment

- Local development.
- Preview environments.
- Staging for integration testing.
- Fast, reversible, no secrets in code.

### Production deployment

- Managed hosting.
- Managed database and backups.
- Object storage with private-by-default access.
- CDN for public listing media only.
- Secret store for all credentials.
- Monitoring, logging, and alerting.
