# Vowora Documentation

Vowora is a global wedding and event marketplace. The product uses a black-and-white visual system and is being developed by Permetheon and Solvx.

## Technology

- Frontend: React.js
- Backend: Python with FastAPI
- Database: PostgreSQL
- Automation: n8n
- File storage: Supabase Storage or S3-compatible storage
- Cache and queues: Redis

## Roles

Customer, Vendor, Planner, and Admin.
