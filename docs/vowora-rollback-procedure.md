# Vowora Rollback Procedure

## Checklist

1. Create a release marker.
2. Confirm the new release is not healthy.
3. Deploy the previous known-good version.
4. Run migrations backward where applicable.
5. Verify health endpoints.
6. Verify data consistency.
7. Notify stakeholders.

## Status

- **Planned** — rollback procedure is documented, not yet executed.
