# Vowora If Code Crashes

## Diagnosis

1. Check logs and alerts.
2. Reproduce locally without sensitive data.
3. Verify environment variables and dependencies.
4. Inspect queue workers and background jobs.

## Recovery

1. Restart affected service.
2. Re-run failed jobs.
3. Verify database and queue integrity.
4. Notify affected users if needed.

## Verification

- Confirm health endpoints.
- Confirm data consistency.
- Confirm monitoring alerts are clear.

## Escalation

- Escalate to engineering lead if unresolved within 30 minutes.

## Status

- **Planned** — procedures are documented but not yet tested.
