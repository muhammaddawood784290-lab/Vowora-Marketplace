# Vowora Database Migrations

## Migration policy

- Source-of-truth: migration files in the backend repository.
- Run migrations before application rollout.
- Review and approve every migration.
- Never run destructive migrations without a rollback plan.

## Tools

- PostgreSQL migration tooling.
- Database review and restore drills included in the release quality checklist.

## Status

- **Planned** — migration tooling is not yet implemented.
