# Vowora Marketplace Moderation

## Responsibilities

- Verify profiles.
- Review disputes.
- Review flagged content.
- Enforce terms and policies.

## Workflow

1. Flag or report content.
2. Admin reviews evidence.
3. Action: remove, warn, restrict, or close.
4. Record moderation action in audit log.
