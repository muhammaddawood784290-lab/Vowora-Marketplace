# Vowora Code Standards

## Frontend

- TypeScript.
- React 19.
- Vite build.
- oxlint.
- Semantic HTML.
- Keyboard accessible UI.

## Database

- Migration files.
- No destructive migrations without rollback.
- Integer minor units for money.
- UTC timestamps and IANA timezone.

## API

- OpenAPI generation.
- Versioned routes.
- Consistent error responses.
- Audit records for sensitive changes.

## Status

- **Partially implemented** — frontend standards are in place.
- **Planned** — CI style checks.
